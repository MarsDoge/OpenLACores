# Random Instruction Test Suite

The test suite is divided into five sets. Each set contains ten instruction
tests, and each test contains approximately 100 million instructions.

When running a simulation, specify the BIN file corresponding to the test you
want to execute.

The source `.S` file and ELF file for each test are also provided to assist
with debugging.
