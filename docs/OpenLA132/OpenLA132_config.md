#	OpenLA132 配置接口介绍

OpenLA132 处理器 IP 包含一些用于配置的接口。接入到这些接口上的视作配置信息，其应该在处理器运行过程中保持不变，否则可能出现行为异常。

##	顶层总线接口地址路由相关配置接口

OpenLA132 处理器 IP 的 I-BUS、D-BUS、SYS-BUS 总线的地址空间通过顶层的地址窗口配置接口输入的值决定。
配置接口接入值在处理器 IP 复位结束后不能再变动，且建议接入值为常值。

配置 I-BUS 空间有四组地址窗口配置输入 ibus0/1/2/3_*，配置D-BUS空间有四组地址窗口配置输入 dbus0/1/2/3_*。

假设某访问的地址为ADDR，如果 ibus*_valid && ((ADDR & ibus*_mask) == ibus*_base) 判断条件成立，则该访问将路由至 I-BUS 接口；如果 dbus*_valid && ((ADDR & dbus*_mask) == dbus*_base) 判断条件成立，则该访问将路由至D-BUS接口；如果没有任何一个配置地址窗口命中，则该访问路由值 SYS-BUS 接口。

需要注意的是上述配置空间判断采用的地址是虚地址，而不是翻译后的实地址。

需要注意的是在配置空间时，I-BUS 和 D-BUS 不能有重叠空间，否则处理器运行状态未知。

I-BUS 和 D-BUS 的地址窗口配置信息每一组包含 3 个信号，具体说明如下。

| 名称 | 位宽 | 集成相关说明 |
| --- | --- | --- |
| \*bus\*_base | 64 | 地址窗口基址。 |
| \*bus\*_mask | 64 | 地址窗口掩码。|
| \*bus\*_valid | 1 | 地址窗口使能。高有效。|

## 	处理器复位地址配置接口

为方便特殊集成应用场景，允许通过接口配置处理器的复位地址。具体配置信息说明如下：

| 名称 | 位宽	 | 集成相关说明 |
| --- | --- | --- |
| boot_pc | 64 | 启动地址。该接口输入信号在处理器核复位撤销前后的数个时钟周期内必须保持稳定不变。除非必要，强烈建议接入常值0x1c000000。|
